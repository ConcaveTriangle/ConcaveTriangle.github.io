Aegis

A local-first tool for adjusting what appears in a Reddit feed and its comment threads.

In development · Browser userscript

Overview

Aegis is a Reddit feed and comment filter implemented as a browser userscript. It uses local rules, with optional semantic classification through a local proxy.

Preferences and classification

The tool separates what a post contains from whether I want to see it. Something can be informative and still be on a topic I'd rather skip. A negative report is not automatically low quality, either.

Settings control whether matching posts are shown, flagged, or collapsed. Corrections can be recorded when the classification gets something wrong. Local rules work without a server.

Status

An active prototype. There isn't a public installation link yet.
